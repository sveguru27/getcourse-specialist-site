# Сайт Светланы — технического специалиста GetCourse

Одностраничный адаптивный сайт, собранный по предоставленному брифу.

## Файлы

- `index.html` — структура и тексты сайта;
- `styles.css` — дизайн-система и адаптив 360 / 768 / 1024 / 1440+;
- `script.js` — мобильное меню, анимации, три слайдера и просмотр скриншотов в полном размере;
- `offer.html` — публичная оферта на оказание технических услуг;
- `assets/p1-*` — 7 экранов первого проекта;
- `assets/p2-*` — 5 экранов второго проекта;
- `assets/p3-*` — 2 экрана третьего проекта.
- `assets/fonts/` — локальные шрифты и файлы лицензий OFL; обращения к Google Fonts при открытии страницы нет.

Во всех трёх кейсах работают ручные слайдеры: стрелки, точки, клавиши ←/→ и свайп на телефоне. Автопрокрутки нет. Клик по скриншоту открывает его крупнее.

Архив с брифом и неиспользуемые исходные изображения вынесены из публичной папки в `../_private_sources/site_1`. При публикации загружайте только содержимое папки `site_1` и не добавляйте `_private_sources` на хостинг.

Первый экран построен только на типографике: декоративные изображения не используются. Раздел отзывов не выводится до появления согласованных реальных цитат.

Сайт не требует сборки. Откройте `index.html` в браузере или запустите любой статический сервер в этой папке.
